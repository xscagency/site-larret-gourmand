Data AddictComment l'application de caisse Data Addict envoie ses chiffres au site

La caisse envoie un service en POST à cette adresse, avec l'en-tête Authorization: Bearer <clé> et un corps JSON du type :

{"date":"2026-10-29", "burgers":{"L'Américain":17, "Le BBQ":14}, "frites":56, "ca_ttc":787, "doubles":2, "rates":0}

Renvoyer un service déjà reçu remplace ses chiffres. Si la clé est régénérée, il faut la remettre dans la caisse.

Bot Telegram dédié aux rappels

1. Dans Telegram, ouvrez @BotFather → /newbot → donnez-lui un nom (ex. « LAG Rappels ») : il vous répond un jeton du type 123456:ABC….
2. Ouvrez votre nouveau bot et appuyez sur Démarrer.
3. Collez le jeton ici et appuyez sur « Détecter la conversation ».

Comment ça tourne

Une tâche planifiée du dépôt GitHub (.github/workflows/rappels.yml) appelle le site chaque matin ; le site n'envoie qu'après 9h et une seule fois par jour. Rien à configurer : aucun secret n'est nécessaire, cet appel ne peut rien faire d'autre que déclencher les rappels prévus.
